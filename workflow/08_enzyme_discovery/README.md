# 08_enzyme_discovery — candidate tire/rubber/plastic-degrading enzymes (not implemented yet)

- curated reference set of characterised enzymes (Lcp, RoxA, RoxB, PET/plastic
  hydrolases, esterases, oxidoreductases) with literature evidence;
- homology searches (DIAMOND/BLASTp, HMMER profiles) against the 06_genes catalogue;
- protein-embedding / machine-learning classifier for distant candidates;
- comparison of ML and homology results, and candidate ranking.
