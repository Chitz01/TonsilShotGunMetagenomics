# metadata/

Small, version-controlled copies of the selection tables produced by
`workflow/01_metadata/run_metadata.sh` on COSMOS, e.g.

- `tonsil_selection_report.txt`
- `tonsil_runs_full.tsv`, `tonsil_sample_runs.tsv`
- `tonsil_run_accessions.txt`, `tonsil_sample_ids.txt`
- `body_site_summary.tsv`

Copy them here after you have reviewed the selection, and commit them, so the
exact sample set used in the thesis is recorded.
